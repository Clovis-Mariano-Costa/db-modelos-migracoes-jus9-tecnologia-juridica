# Security

CLASSIFICACAO: PUBLICO / SEGURANCA
AUTORIZACAO: publicacao permitida com revisao humana
PUBLICACAO: pode publicar
ACESSO: publico
REVISAO: humana recomendada

Nao publicar:

- dados reais;
- dumps de banco;
- backups;
- seeds reais;
- senhas;
- tokens;
- chaves;
- certificados;
- `.env` real;
- dados protegidos por LGPD;
- segredo de justica;
- documentos de clientes, usuarios, estudantes ou parceiros.

Use `.env.example` apenas com placeholders.
