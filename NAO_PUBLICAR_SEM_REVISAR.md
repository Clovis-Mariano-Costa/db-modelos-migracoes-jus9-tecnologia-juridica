# Nao Publicar Sem Revisar

CLASSIFICACAO: PUBLICO / ALERTA DE SEGURANCA
AUTORIZACAO: publicacao permitida
PUBLICACAO: pode publicar
ACESSO: publico
REVISAO: humana recomendada

Antes de publicar qualquer material deste repertorio, verificar se ha:

- dados reais;
- dumps;
- backups;
- migrations com dados reais;
- seeds reais;
- credenciais;
- chaves;
- tokens;
- `.env` real;
- informacao juridica sensivel.

Se houver duvida, classificar como sigiloso e chamar revisao humana.
