Repertorio destinado a modelos, migracoes, orientacoes e estruturas futuras de banco de dados da Jus 9 Tecnologia Juridica.

## Regras principais

- Nao publicar dados reais de usuarios, clientes, estudantes, processos, parceiros ou familia.
- Nao publicar dumps, backups, seeds reais, credenciais, tokens, chaves ou `.env` real.
- Usar apenas exemplos ficticios e `.env.example`.
- Migracoes futuras devem respeitar LGPD, segredo profissional, logs, auditoria e controle de acesso.
